# 爱扒谱（iJipu BP）

把一段音频变成 **iJipu（爱记谱）的 `.jps` 脚本乐谱**：出频谱 → 定调 → 定拍 → 量化成简谱时值 →
导出文本。定位是**人工扒谱的辅助台**，不是"一键完美转谱"。

## 现在能做什么（P0，2026-11-18）

- **顶栏是图标条**（P0.21）：打开音频、**分析**（对当前这一轨重跑判音，见下）、播放/暂停、原音/合成、绘制/选择、重复区间、自动翻页、
  撤销/重做/回开头、全选/全不选/回初稿、导出、保存/打开方案、帮助、左栏开合，连"音名/数字"也是图标（`A` 与 `1`），
  全是 16×16 的线描图标，
  相关按钮用淡底圆角框成一组（文件那组、播放那组、撤销/重做/回开头一组、确认与导出一组）；
  鼠标停上去有中文提示，读屏器靠 `aria-label`。**吸附下拉挪到左栏编辑页最上面了**（用户 m02483，
  顶栏省点地方），深色主题下也是深色（`:root { color-scheme: dark }` + `select/option` 自绘底色）。

- **窄屏（手机 / 窄窗口）顶栏改成左侧抽屉菜单（用户 2026-11-23；2026-11-24 左栏开关也进左簇）**：
  窗口宽度 ≤ **1320px** 时不再把一长排按钮
  挤在顶栏，只留 **品牌图标 → 左栏开关 → 菜单三横 / 录音 / 撤销·重做 /（播放 + 回开头）/
  绘制·选择 / 原音·合成**
  （左栏开关紧跟品牌、菜单在它后面；**左簇靠左，播放 + 回开头居中（回开头在播放后面），
  绘制/选择、原音/合成一起靠右**），其余按钮全进**左侧抽屉**：
  文件（打开音频 / 打开方案 / 保存方案 / 导出）、MIDI（编辑器 / 导入 / 导出）、谱音（全选 / 全不选）、
  播放节拍、循环 / 自动翻页、绘制 / 选择、原音 / 合成、音名 / 数字、帮助。抽屉里每项带图标、名字和热键，
  开着的项有「开」标记；点一项执行完自动收起，点遮罩或按 Esc 也能关。播放速度滑条窄屏也从播放键右边
  挪进抽屉（顶栏那条藏起来）。窗口拉宽会自动回到原来的宽版顶栏，抽屉不会残留。
  录音小条在窄屏也会自己夹在屏幕里（麦克风靠左时不会再超出左边界）。
  窄屏下 **左栏默认不打开**（每次打开都收起，桌面版才记住上次选择）；恢复录音方案也**不自动弹小条**，
  点麦克风才召回。
  **状态栏在窄屏不再被挤成一列竖字**：每段文字单行、整条最多两行，隐藏那串快捷键提示和
  「缓存 / 已存」时间，「爱记谱首页」钉在右下角（不占行，1190/900 也不会出现"只有首页一行"）。

- **录音成谱（2026-11-22）**：顶栏文件组后面多一颗**麦克风**按钮，用来新建"录音成谱方案"——
  点一下在图标下方出现录音小条：**录音 / 暂停录音、停止、分析成谱、左栏**。
  录到的声音**先暂存在本机**（原始 WebM 写 IndexedDB，方案写 `bp.cache`）——录音中/刚录完
  关掉应用，下次打开还能接着干；停止后**先自动出一份频谱**（表格里马上能看到录音的波纹/热力图，
  播放键也能用），再点「分析成谱」复用现有分析链路判音、画到表格。
  文件组的「保存方案」会先弹保存音频对话框（WAV），把音频写下去后同时写 `.bp.json`。
  当前方案有未保存修改时，点麦克风会先问「保存并新建 / 不保存，直接新建 / 取消」。
  **要长期保存或分享，记得点「保存方案」把音频写成 `.wav`；本机暂存只是防丢。**
- 打开音频（桌面壳里是系统对话框 + 按路径读字节；浏览器里 `<input type=file>` 降级），
  在 Web Worker 里算 STFT → 对数（半音）频谱（8192 点、汉宁窗、20 帧/秒、每帧方差归一）。
- 单声部旋律提取：每帧先做**谐波求和**（泛音也算这个基频的分），再用 **Viterbi** 在 88 个半音里找
  一条最省代价的轨迹（跳变代价表里八度便宜、半音贵）→ 连段 → 掐掉首尾的"拖音"。
  **八度纠偏（2026-11-22）**：连段后再用原始频谱对"当前 / 低八度 / 高八度"重打分，
  压基频+二次、抬三次/五次谐波，修"基频弱被判高八度 / 次谐波被判低八度"；只动一个八度，
  证据不足就保留原判。
- 调性分析（Krumhansl 轮廓相关，再走 softmax 归一）给 12 个主音的**可能性百分比**，
  画成 noteDigger 那种一行三段：**左边调名、中间色条（条长 = 百分比、颜色按调固定）、右边百分数**；
  点一行就换调号。调号下拉也在这一组里，组标题可点着收起/展开。
- **节奏分析**：一键在 onset 包络上重找拍点——候选速度（估值的 1/2、1、2 倍）各自找最佳相位，
  选"起声最贴拍点 × 中速先验"最高的那个，再把整条拍线挪到最近的起声峰上；写出 BPM、首拍、拍点、
  重拍和**可信度**（拍点处起声 ÷ 全曲平均起声，0–1）。变速曲子会飘，属已知限制。
- **去谐波**：滑条 0–1，`out = max(0, amp[b] − k·Σ w_h·amp[b−offset_h])`，用原始幅度预测泛音、
  不连锁减空；改完把保存的原始采样重跑一遍分析（频谱/音符/调性/节奏一起更新）。
- 节拍：谱通量 + 自相关估 BPM、找首拍；BPM / 拍号 / 首拍 / **弱起**都能手改，改完立刻重算。
  弱起 = 第 1 小节只算 N 拍（真·不完整首小节，0 表示整小节）；音符表小节线、流线谱、`jps`
  生成、`Ctrl+←/→` 跳小节共用同一套小节边界（`src/jps/bars.ts`）。
- **音符表（钢琴卷帘）**：画布上面**不再有一条"音符表 + 操作说明"的窄栏**（用户 m02483：占地方、信息又重复），
  时间尺直接贴着顶栏；**钢琴键盘在右边**（2026-11-24 从左边挪过来并左右镜像：整列铺白、
  黑键是贴左缘的 I 形黑块、整行高；白键的"脚"在左、伸进黑键格的半块在右），
  横向是时间轴（秒刻度 + 小节号），纵向每半音一行（上高下低）。键盘分界按"真钢琴投影"画两种：
  黑键行在**竖直中心**画一条短线（从黑键右缘画到键盘右缘，两个白键的分界藏在这条黑键中间），
  E|F 与 B|C 之间没有黑键，整格通栏画线 —— 所以从右边看白键是 L/J/T 形、从左边看黑白格等高。
  数字模式下每一行都写简谱数字：**白格行**写在右侧白区（落在这格白键右块的竖直正中，
  相对当前调式是半音的也照标，例如 bB 调里 B 自然写 `1#`、E 自然写 `4#`）；**黑格行**写进黑键块里面、
  从块左缘留 5px（和白格一样），颜色反相（平时浅字，悬停/按下变黄时改深字）。**右上角**常显当前调号（`1=bB`），
  调号右边那把**锁**管上下滚动：锁住之后滚轮改成横向平移，解锁恢复上下换音区；
  **鼠标停在锁或时间轴上会有一句操作提示**（锁：锁住后滚轮改平移；时间轴：拖圈区间 / 点挪播放头）。
  **鼠标所在那一行在网格里压蓝、右侧琴键整格压黄**（白键按 L/J/T 形状压黄、黑键只染自己那块）；
  按住琴键时黄得更实、响该音，松手恢复。**这套键格形制已定稿，不要再改**（见 AGENTS §四）。
- **时间格**按小节/拍/1/4 拍三级画：小节线最亮实线、拍线实线、拍内 1/4 虚线；
  **最小绘制格 = 1/16 拍 × 一个半音**（1/4 拍虚线里再四分），吸附的"格点"档也是 1/16 拍。
  新点出来的音先给这个最小格（120 bpm 下约 31 ms），按住往右拖就一路延长这一个音。
  格子底下铺**频谱热力图**，按最小绘制格（1/16 拍 × 一个半音）取一格一个颜色（阶梯式，不做插值），
  一格不到 1 像素时才按整数倍合并（整曲铺满时有几十万格，不合并会卡）；
  **红＝最热、蓝＝最冷**；归一化用"中位数当噪底、99.5 分位当满格"，
  右侧「显示」里两个滑条调**倍率**和**对比**（颜色深度 = 值 ^ 对比 × 倍率）。
  音块上同时写音名和简谱数字（换调号数字同步重算），鼠标停在表格里时，
  **"音名 · 简谱数字"小牌子跟着鼠标走**（不再是固定在右上角，也不带"点一下试听"那行字）。
- **两种点法**（对应 noteDigger 的铅笔/箭头，热键都是**反引号** `` ` `` 来回切，**默认是选择**；
  选择模式下按住 **Alt** 也能临时当绘制用，松开恢复）：
  - **选择**：点一下试听、不动谱面；可以**拖音符改音高/位置、拖右缘改时值**（用户 m02483）；
    **不能画音、不能删音、点音符也不改确认状态** —— 一进来就是这个，免得手一抖画出个音。
  - **绘制**：点一格 → 响这个音 + 播放头挪过去；点已有音符 → 确认/取消确认（确认过的才是"要扒的音"）；
    空白处按住拖 → 直接画一个音；**右键点音符 / 选中后按 Delete 删音**；
    拖音符中间 → **上下改音高、左右改位置**（往上拖就是升 key）；
    拖右边缘 → 改时值（手停在右缘时光标会变左右箭头）。选中音符后 `↑/↓` 也能改半音，`Shift+↑/↓` 一个八度。
  - **绘制模式独有的**：画新音、删音、改确认 —— 这三样在选择模式里不做（用户 m02483）。
  - **选择工具三种模式**（用户 m02483，参照 noteDigger）：**块选**（点音符只选它一个；空白处拖一个矩形，
    选中"音头在框里 + 音高在行范围里"的音）/ **整列**（点一个音，选中同一时间范围、时值有重叠的所有音；
    空白处横着拖一条竖带，按时间重叠选）/ **整行**（点一个音，选中同一音高的所有音；空白处竖着拖一条横带，
    按音高选）。按 `Alt+R` 或再点一次「选择」按钮轮换，按钮图标跟着变（块选虚线矩形 / 整列竖带+左右箭头 /
    整行横带+上下箭头）；拖的时候画半透明选择框，松手才落选择。**多选后按住其中一个音拖，整组一起移**
    （时间、音高用同一个位移；`↑/↓` / `Shift+↑/↓` 也整组移）。反引号仍然只切「绘制 / 选择」，不管模式。
  - 两种模式下，**点格子都会先响该音高、再把播放头挪到点的地方**（包括重复区间里面 ——
  区间带里不再"拖整段"，想挪区间请拖两端握柄或重新在时间尺上划）。
- **撤销 / 重做**：`Ctrl+Z` 撤销、`Ctrl+Shift+Z` 或 `Ctrl+Y` 重做，工具条也有按钮；最多 **200 步**，
  **一次拖动算一步**（不会撤到半路）。
- **热键**（用户 m02483）：`Ctrl+O` 打开音频、`Ctrl+J` 打开方案、`Ctrl+S` 保存方案、
  `Ctrl+E` 导出 .jps、`Ctrl+]` 收起/展开左栏、`Ctrl+L` 锁定/解锁钢琴键盘、
  `Alt+L` 重复区间、`Alt+N` 自动翻页、`Alt+Z` 音名/数字互换、`Alt+R` 选择模式轮换、
  `Alt+J` 播放节拍开关、`Alt+S` 把焦点移到播放速度滑条（再用 ← → 调）、
  `F1` 打开帮助。**有热键的按钮/控件，悬浮提示的名称后面会跟一枚热键小牌**
  （例如「打开音频 `Ctrl+O`」），说明里就不再重复这枚热键；帮助面板里也有完整清单。
- **回开头 / 跳小节**：工具条「回到开头」或 `Home`（没圈播放区就回曲子开头，圈了就回区间开头）；
  `Ctrl+←` / `Ctrl+→` 退 / 进一个小节（弱起时第 1 小节只跨 N 拍）。
- **帮助面板**：顶栏最右边那个键盘图标（或问号位）点开，里面列了全部按键、快捷键、鼠标操作。
  只回退音符表，不回退播放头/视野/模式。
- **时间尺**高 36px（两行：秒刻度 + 第几小节）。在时间尺上**按住拖** = 框播放时段（自动开循环，
  `Shift` 早就不需要了）；**点一下** = 取消时段、播放头挪到点上。框好的时段**外面会压暗**，
  划的时候光标变左右箭头。
- **吸附**（编辑页最上面；默认「格点」= 1/16 拍：点哪一格就画哪一格；另有 拍 / 小节线 / 关）、**重复区间**（在时间尺上按住拖出区间就自动打开循环）、
  **自动翻页**（播放头贴到右边缘就推一屏）、
  **全选 / 全不选**、右侧栏可收起（工具条最右的图标，用的就是「爱出片」那张
  `public/icons/右侧边栏.svg`，不自己画）。
- **清谱类操作要先确认、也能恢复**（用户 m02483）：「全不选」「回到初稿」「分析」（重新判音）会先弹确认框，
  写清楚会影响多少个确认音；确认后状态栏出现 **恢复「…」** 入口，点它（会再确认一次）就能把音符和参数铺回去。
  这三步同时进撤销栈（Ctrl+Z），快照也落 localStorage（`bp.recovery`），**重启以后还能恢复**。
- **打开音频默认一屏 20 秒**（0–20s，看后面靠横向滚动条或 Shift+滚轮）；比 20 秒短的曲子仍整首显示。
  一屏几秒可以调（调节页「显示」组）：**2–60 秒**，默认 20 秒。
  要一次看全曲：Ctrl+滚轮往外缩。
- **行高可调**（用户 m02483）：调节页「显示」组里的行高滑条，**10–26px**，
  默认 14px。钢琴键形制不变，只是每格跟着变高变矮；键名/音符标签的字号也自动缩放。
  **第一行音高会记住**：上下换音区后存进 localStorage，重开还是上次那个位置（用户 m02483 第 4 条）。
- **键格**：每个半音一格、**格子高度全都一样**（默认 14px，可在设置里调到 10–26px）。黑键行中线只画到黑键左缘，两个白键直接
  相接处（E|F、B|C）画通栏线；黑键是右侧贴边、占 62% 宽、整行高的黑块（左端 2px 圆角）。
  音名模式标 `C4` 这类名字（只在 C 上）；数字模式按当前调式在左侧写简谱数字（`1'`、`2`…，
  调外音不写）。键列上方、时间尺左边那格显示当前调号，形如 `1=bB`。
- **鼠标**：滚轮 = 上下换音区（**锁住之后变成左右平移**）；**Shift+滚轮 = 左右平移**；**Ctrl+滚轮 = 横向缩放**（时值比率，
  以光标指着的那一拍为锚点，约 1.25 倍/格；Mac 上 Cmd+滚轮 也行）。
  左侧栏的滑条也认滚轮 —— 鼠标停在滑条**或它那一行**上滚就是微调它（Shift 五倍步长），左栏不会跟着滚；
  行高、屏宽、倍率、对比、去谐波、播放速度这几条都一样（用户 m02483 追加要求）。
  放大到一屏装不下整首时，音符表下面那条**横向滚动条**就能拖（装得下时它铺满并置灰，
  一直看得见，不会"找不到"）。
- **播放速度**（顶栏播放键右边）：**0.5×–2×**，默认 1×，只改快慢不改音高；
  滑条右边一直显示当前倍率（如 `1.05×`），鼠标停上去还有名称 + 热键 + 说明。
  鼠标停上去才显示名字和说明（"播放速度 / 只改播放快慢，不改音高；当前 1.05×"），
  停在这条上滚轮也能调。播放中拖也立刻生效（音频模式直接改 buffer 的 playbackRate；
  合成音按当前位置重排一次）；值记在 localStorage（`bp.playRate`），下次打开还是这个速度。
- **顶栏「分析」= 一键出初稿**（`adj` 之后加的）：按「分析」页当前选的那一轨（混音 / 人声 / 伴奏）重新判音，
  音符铺到表上并**全部当谱音**，jps 立刻生成；再人工听、改。「全选」在还没有音时也走这条路。
- **顶栏「和弦」= 和弦分析**（用户 m02483，从 noteDigger 的 `plugins/chordEst.js` 复刻）：
  对当前这一轨的频谱算 chroma（12 音级）→ 169 个和弦模板（14 种和弦 × 12 根音 + 无和弦）匹配 →
  HMM + Viterbi 解码（转移概率里带乐理规则：上行纯四度、下行三度、挂留解决、同根音变复杂要罚分）。

**只想调界面/逻辑**：`tauri-dev.bat` 双击就跑（等价于设好三处环境后 `npm run tauri:dev`），

**只想在浏览器里看**：`npm run dev` 后开 http://localhost:5175 —— 浏览器模式下"打开音频"走文件选择框、
导出走 Blob 下载，其余（频谱/卷帘/简谱/播放）与桌面端同一套代码。

桌面构建的环境说明：这台机器**没有 MSVC**，用的是 Rust 的 **GNU 工具链**
（`stable-x86_64-pc-windows-gnu` + winlibs MinGW64 的 gcc），并且
`CARGO_HOME` / `RUSTUP_HOME` 指向工作区里的 `.cargo` / `.rustup`，不在默认的 `~\.cargo`。
`scripts\tauri-env.ps1` 会按脚本位置推导工作区、把这三处设进当前会话；
**不 dot-source 就会出现"cargo 找不到 / 链接器找不到"**。
你自己的机器若有 MSVC（VS Build Tools）+ 默认 rustup，可以完全跳过这一步。

## 为什么这样分工

- **引擎是 vendor 不是依赖**：`vendor/engine` 从 `../ijipu/packages/ijipu-engine/src/engine` 逐字节同步，
  `vendor/ENGINE-SNAPSHOT.json` 记录源提交与哈希；`npm run check:engine` 一比对就知道有没有被改过。
  这样"我们生成的 jps 对不对"和"iJipu 打开它长什么样"是同一套代码说了算。
- **DSP 全在前端、全是纯函数**：`analyzeSamples(samples, sampleRate)` 只吃 `Float32Array`，
  所以 Node 里能用合成正弦当夹具跑断言（见 `scripts/smoke.ts`）。
- **秒轴与拍轴分开**：分析结果存秒（贴着音频），量化后才变成 tick。改 BPM 不动分析结果。

## 回爱记谱 / 在爱记谱打开

- 状态栏和「设置 → 关于」都有 **爱记谱首页**：网页版本窗口返回 `ijipu.pages.dev`，
  桌面壳交给系统浏览器（不会把应用窗口困在介绍页）。
- 「jps 源码」面板有 **在爱记谱打开** / **复制打开链接**：
  - **桌面版**：先找本机的爱记谱桌面应用（`%LOCALAPPDATA%\Programs\iJipu`、`Program Files`、`PATH`、
    `App Paths\ijipu.exe` 注册表），找到就把当前 `.jps` 写成临时文件交给它打开
    —— **不受 8000 字链接上限限制**；一个都没找到才回退网站方式。
  - **网站 / 网页版**：用 `https://ijipu.pages.dev/app/?jps=<encodeURIComponent(源码)>` 打开当前生成的 `.jps`。
- 地址与 8000 字上限集中在 `src/brand/links.ts`，上限跟 iJipu 的 `JPS_PARAM_MAX_LEN` 对齐；
  只有走网站方式且超过 8000 字时才提示先导出 `.jps` 再在应用里打开。
- `.jps` 文件本身仍是纯文本，链接方式是 UI 现拼的，不往谱面里塞长 URL。

## 踩过的坑

**1. 帧时刻要取"窗口中心"。** 8192 点窗长 186ms，若按窗口起点计时，500ms 处换音会被记成
400ms，量化出 `0.75 拍`、末音还要做连音线。现在 `computeSpectrum` 的窗口以帧时刻为中心，
谱上 500ms 换音就是 500ms（`scripts/smoke.ts` 有一条专门守它）。

**1.5 半音核不能只靠"取整的范围"截断。** `buildLogMap` 每个半音 bin 用余弦核（±2/3 半音、
边界处权重要降到 0）。以前只靠 `lo..hi` 取整来圈范围，没判断"距离超出 2/3 半音就权重 0"，
余弦过了 π 又绕回正值 —— 低频相邻半音互相吃能量（F2 有近一半算进 F#2）。表现是
**和弦识别把 F 大三判成 Faug（C3 漏成 C#3）**，热力图低音区也糊。现在超出范围直接 `continue`，
最底下几个半音（A0 一带半音间距比 FFT 分辨率还窄）退化成"最近的 FFT bin"兜底。
实测同一段 C–Am–F–G 的合成音频，修之前判成 `C / Am / Faug / G`，修之后是 `C / Am / F / G`。

**2. Low 完整性级别。** 本机 `D:\Coding\JianpuScript` 带 Low 标签，编出来的
`ijipu-bp.exe` 继承 Low，运行时 `Failed to setup app: 拒绝访问。 (os error 5)`（WebView2
建不了用户数据目录）。一次性修（管理员 PowerShell）：

```powershell
icacls "D:\Coding\JianpuScript" /setintegritylevel M /T
```

不提权的临时办法：把 `ijipu-bp.exe` + `WebView2Loader.dll` 拷到 `%LOCALAPPDATA%` 下再跑
（新文件继承 Medium；已实测能开窗、能扒谱）。

**3. GNU 链接器的 `.rsrc merge failure` 警告**（`multiple non-default manifests`）不影响产物，
是 MinGW 嵌资源的老毛病；MSVC 工具链不会出。

**4. `tauri::Builder::icon()` 在 tauri 2.12 里没有这个方法。** 想换窗口/任务栏图标不能链在
builder 上（编译报 `no method named 'icon'`），要在 `.setup()` 里拿窗口再设：

```rust
if let Some(win) = app.get_webview_window("main") {
    if let Ok(icon) = tauri::image::Image::from_bytes(include_bytes!("../../public/icons/logo-bp.png")) {
        let _ = win.set_icon(icon);
    }
}
```

需要 `use tauri::Manager;`，并在 `Cargo.toml` 打开 `tauri = { version = "2", features = ["image-png"] }`
（不开这个 feature 解不了 png）。

**5. `tauri icon` 要求正方形图。** `Logo-bp.png` 是 1673×1669，差 4 像素会被拒：
```powershell
npm run tauri -- icon "D:\Coding\JianpuScript\矢量图\Logo-bp.png" --fit contain
```

**6. 不要用 shell 改含中文的文件。** 工作区规矩：中文文件只用编辑器工具改，`Get-Content | Set-Content`
会把编码改坏。

## 分轨（桌面专属）

人声/伴奏分离跑在 Rust 里（`ort` + htdemucs ONNX），网站/插件端不渲染入口。

1. 把 `htdemucs_ft_vocals.onnx` 放到 `%APPDATA%\com.ijipu.bp\models\`（301 MB，MIT）。
2. 把 `onnxruntime.dll` 放到 exe 旁边（或设 `ORT_DYLIB_PATH`）。
3. 打开音频 → 「分析」页「分轨（实验）」→「分离人声」；完成后可切「混音 / 人声 / 伴奏」：
   **热力图和播放音源一起切**——看哪轨就听哪轨；正在播时会从当前位置换到那一轨。

实测：36 秒真人声 25 秒分离完（RTF 0.5×）；模型首次加载 5–6 秒。

## 分离模型怎么装（二选一）

1. **装模型包**：跑 `dist-model/ijipu-bp-sep-model-setup.exe`（140 MB，NSIS 打的），
   它把模型和 `onnxruntime.dll` 一起装到 `%APPDATA%\com.ijipu.bp\models`。
2. **应用内下载**：右上角齿轮 → 设置 → 「分轨（实验）」→ 点「下载模型（302 MB，hf-mirror）」，
   65 秒左右下完（实测），下完当场可用。
   也可以点「打开镜像网页 / 打开 HuggingFace」自己下，再手动放到上面那个目录。
